# 📅 Todays

> **체크리스트 · 할 일 · 루틴을 한 곳에서 관리하는 iOS 앱**

---

## 📱 프로젝트 소개

**Todays**는 매일 해야 할 일을 가볍게 적는 **체크리스트**, 반복되는 습관을 횟수와 시간으로 기록하는 **루틴**, 그리고 앞으로 추가될 **할 일**을 하나의 앱에 합친 iOS 앱입니다.
작업의 우선순위를 직관적으로 파악하고 일정을 효율적으로 관리할 수 있도록 단계적으로 만들고 있습니다.

> 🚧 **개발 중인 프로젝트입니다.** 아래 기능 중 일부는 아직 준비 중이에요.

## ✨ 기능

### 🧭 하단 메뉴바
- **체크리스트 · 할 일 · 루틴 · 계정** 네 개의 탭
- iOS 26의 **리퀴드 글래스** 느낌의 반투명 캡슐형 바 (iOS 26 미만에서는 블러 배경으로 대체)
- 탭을 선택하면 선택 표시가 미끄러지듯 이동하고, 아이콘이 튀어 오르며 가벼운 진동이 느껴져요.
- 목록을 스크롤하면 바가 **작아졌다가**, 반대로 스크롤하면 다시 커져요.

### ✅ 체크리스트
- 상단에 **오늘 날짜**(요일, 월/일) 표시
- **+ 버튼**을 누르면 목록 아래에 입력 줄이 생기고 바로 항목을 추가
- 항목을 눌러 **수정**, 왼쪽으로 밀어서 **삭제**, 체크한 항목 **한 번에 삭제**
- 항목이 없을 때는 + 버튼 아래에 화살표와 안내 문구 표시

### 🔁 루틴
- **날짜 줄**: 왼쪽 위에 월을 표시하고, 아래 한 주의 날짜를 좌우로 넘기며 선택
- **월 달력**: 월을 누르면 한 달 달력으로 펼쳐지고, 날짜 아래 점으로 달성 정도를 표시
- **루틴 | 통계** 전환
- **루틴 만들기** (이름, 아이콘, 색상, 빈도, 알림, 목표)
  - 아이콘: SF Symbols 또는 이모지, 색상 8가지
  - 빈도: **일일 / 주간 / 월간 목표** (일일 목표는 반복 요일 선택)
  - 목표: **횟수** 또는 **시간**
  - 더 보기: 목표 초과 기록 허용, 한 번 누를 때 늘어나는 양, 시작 날짜
  - 알림: 정해진 요일·시간에 로컬 알림
- **기록하기**: 목록의 큰 동그라미 안에 횟수/시간이 표시되고, 누를 때마다 설정한 만큼 증가
- **상세 화면**: 큰 동그라미, **타이머**(초 단위 기록), 초기화, **건너뛰기**(일/주/월 단위), 루틴 편집, 루틴별 통계
- **순서 변경**: 목록의 루틴을 끌어서 정렬
- **통계**: 주간 달성 현황, 최근 30일 달성률, 루틴별 연속 달성 기록, 루틴 하나의 통계 화면(현재/최장 연속, 누적 기록, 최근 기록 그래프)

### ⚙️️ 설정
- 화면 모드 (시스템 / 라이트 / 다크)
- 알림 전체 켜기·끄기
- 체크리스트 전체 초기화, 앱 버전 정보

## 📂 프로젝트 구조

```
Todays/
├── MyApp.swift               앱 시작점
├── ContentView.swift         하단 메뉴바와 탭 화면 연결
├── ChecklistView.swift       체크리스트 화면
├── RoutineView.swift         루틴 화면 (날짜 줄, 목록, 통계 전환)
├── Routine.swift             루틴 데이터 구조와 계산
├── RoutineEditor.swift       루틴 편집 화면
├── RoutineProgress.swift     루틴 동그라미와 상세(기록) 화면
├── RoutineParts.swift        날짜 줄, 아이콘, 색상 등 작은 부품
├── RoutineStatsView.swift    루틴 통계 화면
├── RoutineStatDetail.swift   루틴 하나의 통계 화면
├── MonthCalender.swift       펼쳐지는 한 달 달력
├── IconPicker.swift          아이콘/색상 선택 화면
├── AccountView.swift         계정 화면
├── NotificationManager.swift 로컬 알림 등록
├── BarScroll.swift           스크롤에 따라 메뉴바를 줄이는 기능
└── Screens.swift             준비 중인 화면 (할 일)
```

## ▶️ 실행 방법

1. 저장소를 내려받아 `Todays.xcodeproj`를 Xcode로 엽니다.
2. 상단에서 실행할 iPhone 시뮬레이터(또는 연결한 iPhone)를 선택합니다.
3. 실제 기기에서 실행하려면 **Signing & Capabilities**에서 본인의 Team을 고르고 **Bundle Identifier**를 겹치지 않는 값으로 바꿔 주세요.
4. `⌘R`로 실행합니다.

**요구 사항**
- iOS **17.0 이상**
- 리퀴드 글래스 효과(`glassEffect`)를 쓰려면 **Xcode 26 이상**이 필요해요.
- 루틴 알림을 받으려면 처음 알림을 켤 때 나오는 권한 요청을 허용해 주세요.
